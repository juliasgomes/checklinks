Primeira solução

O processo com o DevTools do navegador

  1. Abra a rede social e role a página até carregar os posts.
  2. Aperte F12 e abra a aba Console.
  3. Cole a base da planilha no código, entre as crases.
  4. Cole o código no Console e aperte Enter.
ElementsConsoleSourcesNetwork
(function () {
  // 1. Sua BASE EXISTENTE colada abaixo:
  const baseAntigaTexto = `
https://www.instagram.com/p/DK0HHaguc89/
https://www.instagram.com/p/DLMyUR9ts8F/
https://www.instagram.com/reel/DK-CFkHO0XJ/
...
`;

  // 2. IDs que já estão na base
  const idsNaBase = new Set(baseAntigaTexto.match(/[A-Za-z0-9_-]{9,22}/g) || []);

  // 3. Varre os links da página
  const novos = new Map();
  document.querySelectorAll('a[href*="/p/"], a[href*="/reel/"]').forEach(a => {
    const url = a.href.split('?')[0];
    const m = url.match(/\/(p|reel|reels)\/([A-Za-z0-9_-]+)/);
    if (m && !idsNaBase.has(m[2])) novos.set(m[2], url);
  });

  // 4. Mostra o resultado
  console.clear();
  console.log(`--- CHECK DE LINKS: ${novos.size} POST(S) NOVO(S) ENCONTRADO(S) ---`);
  novos.size ? novos.forEach(u => console.log(u))
             : console.log('Todos os links desta página já existem na sua base!');
})();

Para utilizar, basta seguir as instruções da extensão:

  1. Primeiro escolha a planilha relacionada à marca em que está trabalhando.
  2. Depois escolha qual marca* quer verificar.
  3. Por último, o canal em que vai fazer o check.
  4. Se estiver tudo certo, aparece uma mensagem avisando (verde). Se faltar algum link, eles aparecem em vermelho.

*Facebook não integra esta checagem, pois limitações de acesso externo impedem a leitura dos links pela ferramenta de monitoramento.
